# Jupyter Notebook

`cat_dog_classifier_workflow.ipynb` 把 NumPy 原始版的主要流程放在一个 Notebook 中，方便逐段阅读和运行。

推荐使用 VS Code 打开，并选择已经安装 NumPy、Pillow 和 Jupyter 的 Conda 环境。

也可以在项目根目录运行：

```bash
python3 -m pip install -r notebooks/requirements.txt
jupyter notebook notebooks/cat_dog_classifier_workflow.ipynb
```
