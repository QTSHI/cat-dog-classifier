# 猫狗分类器结构设计

中山大学石全涛

## 输入输出
1. 训练数据猫和狗的照片，验证数据，测试数据
2. 输出 猫/狗


## 数据集来源
来源于互联网，kaggle https://www.kaggle.com/datasets/princelv84/dogsvscats


## 数据预处理
有1w猫的训练数据，1w狗的训练数据
测试数据分别12500
格式jpg 大小不定
```
将图片处理为了rgb三通道，大小为128*128的jpg图片，中心裁剪✅
```
## 模型设计与超参数，CNN
1.设置随机的权重矩阵
2.用数据来模拟
3.损失函数，训练次数
4.梯度下降法找最小损失

```
Conv -relu - pool -Conv-relu- pool -Flatten -FULLCONNECT-output

```
