# 猫狗分类器结构设计

中山大学 石全涛

## 1 项目目标

输入猫和狗的图片，让模型判断图片里是猫还是狗。

- 输入：RGB 图片，大小为 $128\times128$；
- 输出：猫或狗；
- 类别标签：猫为 `0`，狗为 `1`。

## 2 数据集

数据来源：[Kaggle Dogs Vs Cats](https://www.kaggle.com/datasets/princelv84/dogsvscats)

当前项目中的数据数量如下：

| 数据 | 猫 | 狗 | 合计 |
| --- | ---: | ---: | ---: |
| 训练数据目录 | 10,000 | 10,000 | 20,000 |
| 测试集 | 2,500 | 2,500 | 5,000 |

训练数据按照 8∶2 划分：

- 训练集：16,000 张；
- 验证集：4,000 张；
- 独立测试集：5,000 张。

猫和狗的数量相同，不存在明显的类别不平衡问题。

## 3 图片预处理

原始图片的尺寸不同，预处理时进行了以下操作：

1. 统一转换成 RGB 三通道；
2. 从图片中心裁剪并缩放到 $128\times128$；
3. 保存为 JPG 图片；
4. 训练时把像素值缩放到适合模型计算的范围。

选择 $128\times128$ 是因为这个尺寸能保留基本的轮廓和纹理，同时不会让计算量太大。中心裁剪比较简单，但可能会裁掉位于边缘的猫或狗。

使用 RGB 是为了保留颜色、亮度和纹理信息。亮度已经包含在 RGB 数值中，所以没有单独增加亮度通道。

*AI优化的PyTorch 版本还增加了随机裁剪和水平翻转，让同一张图片在训练时产生一些变化，减少模型死记训练图片的情况。*

## 4 模型结构

模型使用一个简单的卷积神经网络（CNN）：

```text
输入图片
  ↓
卷积层1 → ReLU → 最大池化
  ↓
卷积层2 → ReLU → 最大池化
  ↓
展平 → 全连接层
  ↓
猫 / 狗
```

具体结构：

| 层 | 设置 | 输出大小 |
| --- | --- | --- |
| 输入 | RGB 图片 | $3\times128\times128$ |
| 卷积层1 | 8 个 $3\times3$ 卷积核 | $8\times128\times128$ |
| 最大池化1 | $2\times2$ | $8\times64\times64$ |
| 卷积层2 | 16 个 $3\times3$ 卷积核 | $16\times64\times64$ |
| 最大池化2 | $2\times2$ | $16\times32\times32$ |
| 展平 | 转成一维 | 16,384 |
| 全连接层 | 输出两个分数 | 2 |

卷积层使用 $3\times3$ 卷积核、步长 1 和填充 1，因此卷积前后的图片宽高不变。池化层再把宽高缩小一半。

ReLU 会把小于 0 的值变成 0。它计算简单，也能给网络加入非线性。没有在隐藏层使用 Sigmoid，是因为 Sigmoid 在输入绝对值较大时梯度会变小，深层传播时更容易出现梯度消失。二分类概率由最后的 Softmax 和交叉熵处理。

## 5 训练设置

项目中有两个版本。

### 5.1 NumPy 手写版

- 批量大小：8；
- 训练轮数：5；
- 学习率：0.01；
- 优化器：SGD；
- 损失函数：交叉熵；
- 模型文件：`输出/best_model.npz`。

这个版本手动实现了卷积、池化、反向传播和参数更新，主要用于理解神经网络的底层过程。

### 5.2 PyTorch 版（AI优化）

- 批量大小：32；
- 训练轮数：10；
- 学习率：0.001；
- 优化器：Adam；
- 损失函数：交叉熵；
- 数据增强：随机裁剪、水平翻转；
- 模型文件：`输出/PyTorch/best_model.pt`。

PyTorch 版本使用自动求导和 `DataLoader`，并且可以自动选择 CUDA、Mac MPS 或 CPU。两个版本的模型保存在不同位置，不会互相覆盖。

## 6 评价方法

训练过程中记录：

- 训练损失和训练准确率；
- 验证损失和验证准确率；
- 每一轮的训练时间。

测试阶段记录：

- 测试损失和测试准确率；
- 混淆矩阵；
- 猫的识别正确率；
- 狗的识别正确率。

## 7 当前结果

NumPy 手写版使用完整数据训练 5 轮。最后一轮同时取得本次训练的最高验证准确率，结果如下：

| NumPy 指标 | 结果 |
| --- | ---: |
| 最终训练损失 | 0.4132 |
| 最终训练准确率 | 80.99% |
| 最终验证损失 | 0.5001 |
| 最佳验证准确率 | 76.80% |
| 测试损失 | 0.5015 |
| 测试准确率 | 76.24% |
| 猫识别正确率 | 74.12% |
| 狗识别正确率 | 78.36% |
| 总训练时间 | 678.73 秒 |

NumPy 测试集混淆矩阵为：真实猫中 1,853 张预测正确、647 张预测为狗；真实狗中 1,959 张预测正确、541 张预测为猫。完整记录保存在 [`numpy_evaluation_summary.json`](../输出/numpy_evaluation_summary.json)。

PyTorch 版本训练了 10 轮，验证准确率最高的模型出现在第 9 轮。独立测试集结果如下：

| 指标 | 结果 |
| --- | ---: |
| 最佳验证准确率 | 80.58% |
| 测试损失 | 0.4467 |
| 测试准确率 | 80.48% |
| 猫识别正确率 | 79.80% |
| 狗识别正确率 | 81.16% |

测试集共有 5,000 张图片，其中预测正确 4,024 张，预测错误 976 张。猫被预测为狗 505 张，狗被预测为猫 471 张，两个类别的错误数量比较接近。

从 [误判样本图](../输出/PyTorch/misclassified_examples.png) 可以看到，错误常出现在低光照、主体很小、遮挡、局部特写和多动物场景中。测试集中还存在 Logo、无动物图片和 “No Photo Available” 等异常数据，这些图片也会影响结果。

完整结果见 [混淆矩阵](../输出/PyTorch/confusion_matrix.png) 和 [误判明细](../输出/PyTorch/misclassified_samples.csv)。

在当前两套配置下，PyTorch 版测试准确率比 NumPy 手写版高 4.24 个百分点。由于 PyTorch 版同时使用了 Adam、归一化和数据增强，这个差异不能只归因于框架本身。
